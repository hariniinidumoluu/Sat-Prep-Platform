# Sat-Prep-Platform
## PROBLEM: 
Many students struggle to prepare for standardized exams like the SAT, ACT, and AP exams because high-quality tutoring and realistic practice can be expensive or limited. I want to create a free platform that provides realistic practice questions, identifies students' weak areas, and helps them understand their mistakes through personalized explanations and targeted practice. My goal is to make high-quality test preparation more attainable for all students while reducing the stress and burnout that often come with preparing for these exams. 

## PROJECT IDEA:
I plan to build a free SAT preparation website with a Java backend that provides realistic practice questions for both Math and Reading & Writing, identifies students' weaknesses, and helps them improve through personalized explanations and targeted practice. Similar to Elite Prep, but with a more accessible and personalized approach, my goal is to provide high-quality test preparation completely free while tracking students' progress and eventually expanding to ACT and AP exams.

## MVP Features:
- SAT Math and Reading & Writing practice quizzes.
- Automatic grading and identification of weak topics.
- Explanations and targeted follow-up practice.
- Student score and progress tracking.

## Tech Stack:
- Java: Quiz logic, grading, and progress tracking.
- HTML/CSS: Website interface.
- Bash: Compiling and running the Java program.
- File I/O: Storing questions and student progress.
